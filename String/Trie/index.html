字典树 (Trie)

字典树（Trie） 是一种利用字符串公共前缀共享存储空间的树形数据结构。每条边代表一个字符，从根节点到某个节点的路径表示一个前缀，通过终止标记区分完整字符串与普通前缀。
算法流程

  • 初始化：创建根节点，每个节点维护字符对应的子节点及终止标记。
  • 插入：从根节点开始，依次遍历字符串的每个字符；若对应子节点不存在，则创建新节点，否则沿已有节点继续向下。遍历结束后标记字符串结尾。
  • 查询：从根节点开始，依次沿对应字符的边向下查找。若中途不存在对应子节点，则查询失败；若遍历结束，则根据终止标记判断字符串是否存在。
  • 核心思想：公共前缀共享节点，逐字符沿树转移。

普通字典树

用于存储字符串集合，公共前缀共享节点，支持 (O(|s|)) 插入和查询。

vector<array<int, 26>> Trie(1);
vector<int> cnt(1);

void insert(string s)
{
    int u = 0;
    for (char c : s)
    {
        int k = c - 'a';
        if (!Trie[u][k])
        {
            Trie[u][k] = Trie.size();
            Trie.emplace_back();
            cnt.push_back(0);
        }
        u = Trie[u][k];
    }
    cnt[u]++;
}
int query(string s)
{
    int u = 0;
    for (char c : s)
    {
        u = Trie[u][c - 'a'];
        if (!u)
            return 0;
    }
    return cnt[u];
}

01字典树

将整数按照二进制位存储，支持插入和查询最大异或值，时间复杂度均为 (O(B))，其中 (B) 为二进制位数。

vector<array<int, 2>> Trie01(1);

void insert01(int x)
{
    int u = 0;
    for (int i = 30; i >= 0; i--)
    {
        int b = (x >> i) & 1;
        if (!Trie01[u][b])
        {
            Trie01[u][b] = Trie01.size();
            Trie01.emplace_back();
        }
        u = Trie01[u][b];
    }
}
// 查询最大异或值
int query01(int x)
{
    int u = 0, ans = 0;
    for (int i = 30; i >= 0; i--)
    {
        int b = (x >> i) & 1;
        if (Trie01[u][b ^ 1])
        {
            ans |= 1 << i;
            u = Trie01[u][b ^ 1];
        }
        else
            u = Trie01[u][b];
    }
    return ans;
}
